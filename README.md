# Text-Based-Adventure-Game-simple-python-
A simple text-based adventure game built in Python where the player explores a dark forest, solves a riddle, and battles a sorcerer to save the Lost Kingdom. Built using pure Python with no external libraries — beginner friendly and easy to run on any system.

# Features
- 3 unique scenes — Forest, Cave, Final Battle
- Inventory system — collect and use items
- Win and Lose endings
- Riddle puzzle
- Restart option after every ending

# Story

A dark curse has fallen upon the Lost Kingdom.
The people are suffering and only a true hero can lift it.
You are that hero. Enter the forest, face the challenges,
and save the kingdom — or fall trying.

# Scenes
# Scene 1 — The Dark Forest
- Choose between two paths
- Find a Magic Sword or face dangerous wolves
- Your choice affects the rest of the game

# Scene 2 — The Cave
- Solve an ancient riddle carved on the cave wall
- Wrong answer? Try again until you get it right
- Correct answer opens the path forward

# Scene 3 — The Final Battle
- Face the Dark Sorcerer
- Fight with your sword, cast a spell, or negotiate
- Multiple ways to win — or lose!
